# User Guide

## Primeiros passos
1. Cadastrar primeiro produto — `/app/produtos`
2. Abrir Caixa — `/app/caixa`
3. Fazer primeira venda — `/app/pdv`
4. Emitir primeiro relatório — `/app/relatorios`

## Recursos principais
- PDV touch com atalhos rápidos
- Estoque com WAC e alertas de mínimo
- Documentos fiscais A4 e térmicos
- CRM com segmentação automática
